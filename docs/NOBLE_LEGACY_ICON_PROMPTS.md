# Noble Legacy — Talent Icon Prompts

> **Tree:** Noble Legacy (`tree_noble_legacy`)
> **Theme:** Martial prowess, cold discipline, Nordic nobility
> **Total icons:** 25

## Technical Specifications

- **Display size:** 32px normal (at 720p base), auto-scaled
- **Recommended generation size:** 256x256 or 512x512 (scale down for crispness)
- **Format:** Square, PNG with transparency or dark background
- **Must read well against:** Dark panel backgrounds (RGBA ~0.12, 0.12, 0.14)

## Style Guide

All prompts share a consistent style frame to ensure visual coherence across the full set.

**Universal prefix (included in every prompt):**
```
Fantasy RPG ability icon, square format, dark background with subtle vignette, painterly style with clean edges, muted cool tones with gold and steel accents, suitable for a dark medieval Nordic setting, centered composition,
```

**Universal suffix (included in every prompt):**
```
--no text, no letters, no words, no UI frame, no border decoration
```

**Color language:**
| Element | Color | Rationale |
|---------|-------|-----------|
| Weapon skills | Steel / silver | Physical martial actions |
| Stamina effects | Pale green | Matches stamina bar color |
| Blood / damage procs | Crimson red | Matches life bar color |
| Cold / mark effects | Icy blue | Thematic cold nobility |
| Ultimate | Brilliant gold | Matches UI gold accent, capstone power |
